# 给 agent 写文档的要点

写或改 SKILL.md、CLAUDE.md、规则段、交接文档这类给 agent 看的文字时，先读这一页。

- **常驻内容要短。** CLAUDE.md 和规则段每个会话都会加载，只写每次都用得上的要求；细节放进技能或参考文件，常驻处只留一句指向它的说明。
- **同一条规则只放一处。** 需要在别处提到时写指针（技能名或文件路径），不要复制一份。复制的两份迟早会不一致。
- **用正面的说法写要求。** 写“用中文回复”，不写“不要用英文回复”；写清楚该做什么，比列出不该做什么更容易照做。
- **触发条件写清楚。** 技能的 description 和每条规则都要说明在什么情况下适用，让 agent 能判断现在该不该用。
- **删掉说了等于没说的话。** “认真工作”“注意质量”这类话不改变任何行为，删掉。每句话都应该能改变 agent 的某个具体做法。
- **每一步都带完成标准。** 步骤后面写上怎样算做完、怎么检查，agent 才知道什么时候能进入下一步。
